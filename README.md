# MALTWEB — GitHub Pages Edition

Built for phone + GitHub Pages. No PHP, XAMPP, SQLite or laptop server is required.

## Publish
1. Upload all files in this folder to the MALTWEB GitHub repository.
2. Commit the changes.
3. GitHub → Settings → Pages.
4. Select Deploy from a branch.
5. Choose the main branch and /(root).
6. Save.

## Included
Home, search/discover, categories, profiles, events, opportunities, demo login/register, dashboard, create profile and admin prototype.

Login/profile creation are browser-only demos using localStorage. They are not a secure multi-user backend. Later this same frontend can connect to Supabase, Firebase, Node.js or PHP.
